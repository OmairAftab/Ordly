**Project Abstract**

Software project management remains one of the most manual and cognitively demanding processes in the software development lifecycle. Project managers today spend significant time decomposing requirements into tasks, assigning work to developers, tracking progress, detecting risks, and writing daily standup reports — all by hand, relying entirely on individual judgment rather than data. Existing tools like Jira, Trello, and ClickUp are passive task trackers that organize information but offer no intelligence, prediction, or automation. The result is that projects are frequently delivered late, over budget, or with reduced scope — not because developers lack skill, but because the management layer lacks intelligence.

Ordly addresses this problem by automating the full project management lifecycle using artificial intelligence. A project manager pastes a plain English requirement and the system automatically decomposes it into a structured task tree containing tasks, subtasks, dependencies, estimated hours, complexity levels, and priorities — using a Large Language Model invoked through a carefully engineered prompt. A custom rule-based scheduling algorithm then assigns each task to the most suitable developer based on skill matching and workload, and calculates realistic start and end dates automatically. Risk detection is handled by a Logistic Regression classifier trained on synthetic task progress data and deployed as a Flask microservice, which classifies every active task as On Track, At Risk, or Critical on an hourly basis. Daily standup reports are generated automatically every morning using the Large Language Model, eliminating manual status meetings entirely. A human-in-the-loop Decision Automation Engine monitors risk signals and productivity flags to generate plain English corrective suggestions — such as task reassignment or deadline adjustment — which the PM approves, edits, or ignores with one click. A structured Project Insights Panel allows the PM to query live project data through predefined question templates backed by optimized MongoDB queries. Every AI action across all modules is recorded in a fully auditable AI Decision Log with complete plain English explanations, implementing Explainable AI principles that make every automated decision transparent and justifiable.

Ordly is built on React.js, Node.js, Express, MongoDB, and Socket.io for real-time notifications, with Python, scikit-learn, and Flask powering the machine learning layer. The system is designed specifically for small and medium software development teams who need intelligent project management capabilities without dedicated project managers. By combining Large Language Model intelligence, supervised machine learning, and explainable AI into one integrated platform, Ordly transforms a standard project board into a domain-specific intelligent management system that is proactive, transparent, and fully accountable.
